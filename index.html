Azure: Kysymyksiä ja vastauksia

1. Milloin Azure on julkaistu?

2008

2. Mikä on Azuren keskeinen tarkoitus?

Tarjota pilvialusta sovellusten ja sivustojen kehittämistä, testaamista, käyttöönottoa ja hostaamista varten.

3. Mitkä ovat tärkeitä Azuren palveluita sovelluskehittäjille?

Tärkeimmät palvelut sovelluskehittäjille ovat Azure App Service, Azure Static Web Apps, Azure Functions, Azure DevOps, Azure Kubernetes Service ja Azure Container Apps

4. Kuinka paljon erilaisia resursseja ja palveluita Azure markkinapaikassa on tarjolla?

Lähemmäs 50 000.

5. Mistä Azuren palveluiden kustannusten määrät riippuvat?

Kustannusten määrät riippuvat resurssien tyypistä ja asetuksista, ylläpidosta, tilaustyypistä, resurssien käytöstä ja kustannusmallista, alueesta ja vyöhykkeestä sekä marketplace-ratkaisuista.
